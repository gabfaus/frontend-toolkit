# Figma third-party boundary

The official source for `figma-design-to-code` is
`https://github.com/figma/mcp-server-guide` at commit
`ae7e5e5f80da20f1dd7445e0c6ae5ac58a5b0bce`.

The pinned upstream commit has no standalone `LICENSE` file. Its official
README points to the Figma Developer Terms. This repository therefore does not
redistribute the upstream Skill text or a generated snapshot. The two local
`SKILL.md` files are FTK-owned link-only adapters; their provenance and source
hash are recorded in `integrations/figma.lock.json`.
