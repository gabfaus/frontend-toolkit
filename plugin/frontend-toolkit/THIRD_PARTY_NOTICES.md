- Impeccable 4.1.2, Apache-2.0, pinned at commit `63b04e2530f5c7b41ea83c133daab24f34912456`.
- img2threejs 1.5.1, Apache-2.0, pinned at commit `dede5909be4e494b228c801a55dda47439143932`.
- Shadcn CLI/MCP 4.19.0, MIT, resolved by the pinned npm command in `.mcp.json`.
- 21st is a remote MCP service. No 21st plugin or Skill code is incorporated.

See `external-skills.lock.json` and the repository locks under `integrations/` for provenance and update procedures.
